# 第2章实现需求

将原书单机到百万用户的架构演进转成可运行的1/8/10进程本机HTTP实验。实现无状态Web/共享持久会话、轮询与请求故障回退、版本化资料/CAS/幂等、TTL/LRU缓存、异步读副本、静态账户分片、持久outbox及消费者去重、本地版本化边缘资源缓存与诊断计数。

明确最终一致、主库强读及最小版本读；不把TTL等同副本滞后上限。已有数据库拒绝未经迁移改变分片映射。验证Web/缓存/副本故障、主库重启、分片隔离与消费确认丢失。

不宣称无人值守的生产故障切换、在线迁移、真实 CDN 或 GeoDNS 服务、跨地域磁盘同步、生产 TLS/身份或百万用户容量；提供双语文档、设计、真实测试及实测报告。本地 `GeoDNS` 目录和显式 `Fence` 提升是章节里数据中心切换与从库提升的实验模型，不是上述生产系统。
