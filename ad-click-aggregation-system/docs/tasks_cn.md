## 范围

按广告统计过去 M 分钟点击数、每分钟 Top N（默认 100），按用户/IP/国家过滤；处理迟到、重复和部分故障。

- [x] T1. 编写需求/设计，定义事件 ID、event-time、过滤维度、窗口与结果修订语义。

- [x] T4. 实现事件去重、检查点和输出事务，真实进程提交前退出后恢复不重复计数。
- [x] T5. 实现窗口计数查询、精确全局 Top N 与过滤交集；维度成本及候选预算已说明。
- [x] T6. 实现 4 分区、4 独立工作进程/存储与二阶段归并；固定拓扑，动态扩容/迁移仍为生产扩展。
- [x] T7. 实现原始日志重建、独立批对账、哈希异常检测与积压/错误状态；不依赖外部监控供应商。

- [x] T10. 复用有界查询扇出/准入与共享deadline，验证source/worker响应，完整归并候选后精确heap Top N。

## 验收门槛

- 正确性、持久化重启、幂等和故障路径有可重复测试。
- 分布式能力须用实际独立进程/网络验证，模拟实现单独标注。
- 外部云服务/供应商使用可替换适配器；未配置凭据时不能宣称真实服务已验证。
- 原书规模和可用性数字是设计目标，不由本机测试直接证明。
- 仅在用户要求后提交；docs 下 requirements.md/tasks.md 延续不提交的约定。
