# 文件同步系统

第 16 章 Google Drive 的参考实现：分块上传、断点续传、工作区内去重、压缩与
AES-256-GCM 存储加密、修订历史、增量同步、冲突副本、分享撤销和持久化通知。

在本目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e '.[dev]'
.\.venv\Scripts\python -m pytest -q
.\.venv\Scripts\python examples/network_demo.py
```

示例启动真实 API 进程及独立设备进程，验证三块文件同步、中间块修改后只传输变化
块，以及服务重启后设备游标恢复。退出时停止自己的服务并清理临时目录。

持久运行和所有接口参数见[英文说明](README.md)。服务默认每块 4 MiB，文件上限
10 GiB，配额包含保留的修订及正在上传的预留空间。首次上传和重试必须保持请求 ID；
旧版本并发更新生成冲突副本，旧版本删除被拒绝。目录按相对路径建立，不含文档协同编辑。

客户端支持显式 push/pull 和自动扫描同步，本地 `.sync` 保存进度和明文块缓存。服务端对象
真实压缩加密，元数据保留主密钥；这不是端到端加密，需保护数据库及密钥备份。
服务端每次请求检查分享权限，撤销后拒绝新下载；无法远程擦除已有离线副本。

修订保留和垃圾回收显式执行；正在上传的块受保护。归档/恢复接口使用本地冷目录
演示，尚未接入真实云归档。默认仅本机 HTTP，远程部署需要 HTTPS。

当前为 SQLite/本地块存储参考实现，未接入跨地域复制或元数据高可用。
自动同步不是原生文件监控器；设备目录有进程独占锁，并可持久绑定一个工作区。
路径重叠的工作区使用不同且已绑定的设备目录。生产仍需事件保留、重新快照与监控。

[设计文档](docs/design.md)说明取舍；[验收报告](benchmarks/results.md)记录实际结果。

## 自动同步与本轮核对

```powershell
python -m file_sync.cli sync --folder .runtime/laptop --device laptop --space WORKSPACE_ID --interval 1 --poll-wait 1
```

SyncWatcher 每轮默认最多扫描 10,000 个目录项，上传新建/修改、条件删除本地已删
文件，再拉取通知；失败有上限退避，停止等待当前操作。每个设备串行处理，保留的
本地冲突副本不会自动上传；可手动 push 或改名后处理。pull --space ID 也能绑定，
未绑定的库接口保留旧的全工作区拉取语义。明文块磁盘缓存默认 64MiB，不是 RSS 上限。

新增 PUT /file?space=ID&path=PATH&request=ID（可加 base）简单上传，正文最多一个
配置块；/revisions 可传 limit=1..1000。新会话发送 pending，完成发送 upsert，取消
或过期发送 cancelled；重试不重复发送开始事件，未完成文件仍不可下载。客户端整页
应用成功后再持久游标/确认，保留下载期间的新编辑，按已接受修订对账丢失响应。

大块压缩/加密、全文件校验和下载移出全局元数据锁，最终事务复核状态、ACL 和对象
存在性。不可变清单缓存有界，不能绕过当前 ACL/文件头。归档、恢复和 GC 用同一组
跨进程键锁；过期状态先提交再删对象。长轮询只占部分 HTTP 容量，空闲不反复写库，
停服会取消轮询并等待活动请求。SQLite 仍串行写入，GC 可能阻塞；套接字期限不能
强制取消文件系统/SQLite 调用。

详见[章节核对](docs/chapter16-review.md)及[最新进程实测](benchmarks/review-2026-10-24.json)：
中间块修改只下载 4,096 字节，复用 8,192 字节，API 重启后设备进度保持。小样本
不代表生产容量；云复制、数据库高可用、原生移动端和十 GiB 实物测试仍有边界。
