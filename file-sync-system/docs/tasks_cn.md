# Tasks: Design Google Drive

来源：根目录 `System Design Interview.md` 第 16 章，章节起始行 5369。

状态：2026-10-24核心核对完成，116项测试通过；独立API/设备进程、自动扫描同步及重启已验证。
见[章节核对](chapter16-review.md)和[验证报告](../benchmarks/results.md)。

## 范围

任意文件上传下载（不超过 10 GB）、多设备同步、修订、分享和通知；不含文档协同编辑。

## 实施任务

- [x] T1. 先编写需求与设计，划分块存储、强一致元数据、客户端同步及通知服务。
- [x] T2. 实现文件分块、校验和、压缩、重复块去重和真实 AES-GCM 加密适配器，避免自行发明加密算法。
- [x] T3. 实现简单/可恢复上传、下载与修订版本；只有全部块可靠保存后才能发布可见元数据。
- [x] T4. 实现增量同步、设备游标、离线恢复、冲突副本及删除标记，处理并发编辑。
- [x] T5. 实现分享权限、撤销、配额、修订查看及持久化通知；使用长轮询/网络适配器及有界、绑定工作区的扫描器自动同步。
- [x] T6. 设计元数据事务、缓存失效、块引用计数、本地冷数据归档/恢复演示及安全垃圾回收。
- [x] T7. 验证多设备实际进程、上传中断、块损坏、元数据事务失败、通知丢失与重复、权限撤销。
- [x] T8. 报告同步延迟、重复数据节省和带宽，区分本地参考实现与跨地域存储耐久性。
- [x] T9. 提供可运行示例、英/中文 README、设计取舍及实际测试/压测报告，更新根目录状态；未验证的生产规模保持明确。

## 验收门槛

- 正确性、持久化重启、幂等和故障路径有可重复测试。
- 分布式能力须用实际独立进程/网络验证，模拟实现单独标注。
- 外部云服务/供应商使用可替换适配器；未配置凭据时不能宣称真实服务已验证。
- 原书规模和可用性数字是设计目标，不由本机测试直接证明。
- 仅在用户要求后提交；docs 下 requirements.md/tasks.md 延续不提交的约定。
