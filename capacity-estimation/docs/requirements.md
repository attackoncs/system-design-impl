# Chapter 3 Requirements

Provide QPS, storage, bandwidth, cache, node count, concurrency, downtime budget, and sensitivity analysis with explicit units and assumptions. Use Decimal and reject non-finite/out-of-range inputs; distinguish SI from IEC, avoiding floating-point errors, byte/bit confusion, and rounded-down capacity. Output the fields corresponding to each formula and all default assumptions. The original book's latency tables are not treated as current hardware parameters, and estimation is not equivalent to real-world measurement.
