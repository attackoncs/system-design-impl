- 慢网络轮询期间行情读取可用；严格JSON/framing/凭据/查询/管理契约、容量回收、RPC总截止时间/取消、代理与重定向拒绝。

## 实测p99

原始样本：[latest.json](latest.json)。预置20笔卖单，每笔1股、价格100美分；4个并发客户端提交20笔限价101的主动买单，每笔预期完全成交：

| 指标 | 样本结果 |
|---|---:|
| 测量主动买单数 | 20 |
| 主动买单全部完成用时 | 1.3855秒 |
| 完成成交主动单吞吐 | 14.4349笔/秒 |
| 提交至确认成交p50 | 227.75毫秒 |
| 提交至确认成交p95 | 435.91毫秒 |
| 提交至确认成交p99 | 473.58毫秒 |
| 成交笔数 | 20 |
| 日志序号（含genesis与20笔预置卖单） | 41 |
| 主备状态、现金/股份/冻结、事件重放 | 全部一致 |

计时从每个主动单发起HTTP提交，到轮询得到FILLED结果，包含网关持久化、异步撮合、HTTP和客户端轮询；不含预置卖单、进程启动、最终备机追平/行情排空和审计。预置20笔卖单没有计入吞吐分子。测试与压测分开执行。

分位数采用最近秩法。**仅20个样本时p99等于最大观测值**，不能证明稳定尾延迟，更不能等同单撮合函数耗时。当前结果没有达到原书低毫秒尾延迟/高吞吐目标。

本实验未验证长时间压力、跨主机网络、物理磁盘故障、定序器复制或自动切换、真实资金/清算或生产合规。真实网络主备重放不等于完整交易所高可用，四个九和每日十亿订单保持为未证明目标。
