# 第29章验证与性能报告

日期：2026-10-21。Windows11（10.0.26100）、Python3.13.9、四进程回环HTTP、四个独立SQLite数据库，合成账户/持仓及固定模拟时钟。未发送真实交易订单。

## 运行命令

在本目录设置 `PYTHONPATH=src`，并把TEMP/TMP设置到已创建的 `.runtime/tmp`：

```powershell
python -m unittest discover -s tests -v
python examples/network_demo.py
python tools/benchmark.py --pairs 20 --clients 4
```

最终完整测试：**13项通过，16.981秒**。9项核心/存储测试，4项各自运行网关/定序器、主撮合机、备撮合机及行情/报告进程的真实HTTP测试。

## 验证证据

| 场景 | 实际结果 |
|---|---|
| 价格优先与FIFO | 更优价格优先；同价并发卖单按返回的定序序号，先成交5股再成交后一单2股 |
| 部分成交和价差返还 | 限价110买8股以挂单100成交，实际支出800美分，持仓加8，现金无多余冻结 |
| 并发幂等请求 | 同请求10次并发下单只有一个序号/一次冻结；更改价格返回409 |
| 撤单与成交竞态 | 并发撤单和卖出只按序号选择一个结果：撤单先则不成交，卖单先则成交且撤单拒绝 |
| 现金/持仓风险 | 可用资金不足、卖空、未知股票拒绝；部分成交后撤单只释放剩余冻结 |
| 自成交防护 | 主动单剩余取消，无自成交、无重复现金变更 |
| 日限额与时段 | 撤单不返还当日报单量；非时段新单拒绝；次日首条指令释放旧DAY单 |
| 身份与整数 | 他人订单读取404、普通用户内部读取401；拒绝浮点/布尔/字符串价格 |
| 备机追平及切换 | 不可用备机不能提升；恢复追平、停主、提升备机后继续撮合，epoch升为2 |
| 旧主及定序器重启 | 旧主活跃发布409；主备状态哈希一致；备机快照加尾部重启、定序器重启均保留唯一成交和epoch |
| 行情断档 | 停行情超过8条指令，内部feed返回410；行情恢复后快照补齐、重同步次数增加 |
| 客户端增量 | 快照后获取连续价位绝对数量和脱敏成交；过旧游标410；公开成交不含买卖方身份 |
| 报告与K线 | 五笔1股成交生成买方/卖方各五个唯一报告；OHLC=100、成交量5，订单簿余7股 |
| 日志/快照与游标 | 不可变事件删除失败；有效快照加尾部重建投影；损坏快照拒绝恢复；重复行情批次不重复成交 |
| 现金/股份审计 | 总现金3000000美分，AAPL/MSFT各3000股，冻结与开放订单一致，独立重放投影匹配 |

四进程演示实际完成：Bob先卖5股、Carol后卖7股，Alice限价110买8股，以100成交5＋3；Alice现金999200美分、AAPL1008股。停主并提升已追平备机后撤销Carol剩余4股，订单簿清空。最终现金/股份及重放审计一致，K线成交量8。全部实验只清理自己拥有的子进程与临时文件。

## 实测p99

原始样本：[latest.json](latest.json)。预置20笔卖单，每笔1股、价格100美分；4个并发客户端提交20笔限价101的主动买单，每笔预期完全成交：

| 指标 | 样本结果 |
|---|---:|
| 测量主动买单数 | 20 |
| 主动买单全部完成用时 | 1.3855秒 |
| 完成成交主动单吞吐 | 14.4349笔/秒 |
| 提交至确认成交p50 | 227.75毫秒 |
| 提交至确认成交p95 | 435.91毫秒 |
| 提交至确认成交p99 | 473.58毫秒 |
| 成交笔数 | 20 |
| 日志序号（含genesis与20笔预置卖单） | 41 |
| 主备状态、现金/股份/冻结、事件重放 | 全部一致 |

计时从每个主动单发起HTTP提交，到轮询得到FILLED结果，包含网关持久化、异步撮合、HTTP和客户端轮询；不含预置卖单、进程启动、最终备机追平/行情排空和审计。预置20笔卖单没有计入吞吐分子。测试与压测分开执行。

分位数采用最近秩法。**仅20个样本时p99等于最大观测值**，不能证明稳定尾延迟，更不能等同单撮合函数耗时。当前结果没有达到原书低毫秒尾延迟/高吞吐目标。

本实验未验证长时间压力、跨主机网络、物理磁盘故障、定序器复制或自动切换、真实资金/清算或生产合规。真实网络主备重放不等于完整交易所高可用，四个九和每日十亿订单保持为未证明目标。
