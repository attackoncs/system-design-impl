# Tasks: Stock Exchange

来源：根目录 `System Design Interview.md` 第 29 章，章节起始行 15039。

状态：参考实现完成；56项测试、4进程演示和p99实测通过。仅模拟账户/行情；异步主备撮合及人工epoch切换已验证，定序器仍为单点，无自动选主或生产规模证明。

## 范围

股票限价下单/撤单、实时成交与订单簿、交易时段和风险检查、资金冻结；使用模拟行情/账户。

## 实施任务

- [x] T1. 编写需求/设计，定义价格整数单位、订单/成交、序列号、冻结资金及确定性撮合规则。
- [x] T2. 实现入口校验、保守的按用户/股票/日受理股数限额、资金及持仓冻结。
- [x] T3. 实现价格-时间优先限价订单簿、部分成交、撤单及剩余冻结资金释放。
- [x] T4. 实现全序sequencer、事件日志、每股票逻辑订单簿及确定性重演；未做每股票独立进程并行分片。
- [x] T5. 实现成交/行情发布、订单簿增量、快照、蜡烛图及丢失增量后的重同步。
- [x] T6. 实现异步主备复制、快照/恢复、epoch发布隔离及报告流；定序器复制/自动切换另属未实现扩展。
- [x] T7. 为身份/风险/时段规则保留接口，不宣称已获得交易所合规认证，也不向真实交易场所发送订单。
- [x] T8. 验证公平顺序、同价先到先得、撤单竞态、资金守恒、故障重演和行情恢复，报告 p99 延迟。
- [x] T9. 提供可运行示例、英/中文 README、设计取舍及实际测试/压测报告，更新根目录状态；未验证的生产规模保持明确。

## 验收门槛

- 正确性、持久化重启、幂等和故障路径有可重复测试。
- 分布式能力须用实际独立进程/网络验证，模拟实现单独标注。
- 外部云服务/供应商使用可替换适配器；未配置凭据时不能宣称真实服务已验证。
- 原书规模和可用性数字是设计目标，不由本机测试直接证明。
- 仅在用户要求后提交；docs 下 requirements.md/tasks.md 延续不提交的约定。
