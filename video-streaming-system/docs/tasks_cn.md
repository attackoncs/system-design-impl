# 任务：设计 YouTube

来源：根目录 `System Design Interview.md` 第 15 章，章节起始行 4765。

状态：参考实现及 PostgreSQL/S3 扩展已完成，40 项完整测试通过；其余生产扩展另列如下。

## 范围

上传与播放视频，最大 1 GB；多清晰度与不同客户端；不含推荐、评论和直播。

## 实施任务

- [x] T1. 先编写 requirements.md 和 design.md，明确上传、转码、播放状态机及存储/媒体处理接口。
- [x] T2. 实现分片/可恢复上传、校验和、元数据提交与幂等完成；提供预签名上传接口，测试过期及越权。
- [x] T3. 实现持久化转码 DAG、依赖调度、有界进程/编码资源、异步工作进程、重试与持久失败记录；失败不得发布半成品。
- [x] T4. 提供实际媒体转码适配器和固定测试视频；假工作进程与真实转码的验收分别记录。
- [x] T5. 生成多清晰度分段及播放清单，支持客户端选择清晰度、范围读取和本机对象读取边界；云 CDN 接入另列扩展。
- [x] T6. 实现临时文件回收、下架、授权读取及加密接口；说明真实密钥管理与 HTTPS 接入要求。
- [x] T7. 验证上传中断、工作进程退出、任务重复、原始视频检查、元数据回滚、对象缺失恢复和完整播放。
- [x] T8. 比较热门视频 CDN、冷视频源站及编码存储成本，实测本机上传/HTTP 读取延迟和短视频转码时间。
- [x] T9. 提供可运行示例、英/中文 README、设计取舍及实际测试/压测报告，更新根目录状态；未验证的生产规模保持明确。

## 验收门槛

- 正确性、持久化重启、幂等和故障路径有可重复测试。
- 分布式能力须用实际独立进程/网络验证，模拟实现单独标注。
- 外部云服务/供应商使用可替换适配器；未配置凭据时不能宣称真实服务已验证。
- 原书规模和可用性数字是设计目标，不由本机测试直接证明。
- 仅在用户要求后提交；docs 下 requirements.md/tasks.md 延续不提交的约定。
