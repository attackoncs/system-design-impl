| 多清晰度、流式播放、内容保护 | 实际 H.264/AAC HLS、144p 至 1080p 可选、AES-128、授权清单/分片/密钥、字节范围与 HEAD |

| 临时存储回收 | 尝试目录及时清理，READY/FAILED GOP 宽限后回收，保留源和已发布资源 |

客户端使用已签名 URL PUT 到本参考上传入口，再写对象存储；不是云厂商原生直传
URL，也没有部署全球上传中心。编码并发粒度是清晰度，不是逐 GOP 分布式编码再
拼接。原书的多协议和三种内容保护是可选方案，本项目采用 HLS 与 AES。

## 工程与并发修复

- 抽出 pipeline/scheduling/schema/lifecycle，移除割裂 SQL 字符串，保留 VideoService
  公共入口和默认五任务计划。显式重试不能替换已接受计划，Worker 重启不改变计划。
- 领取在获得事务后读取时间，并在实际领取前设置新期限；首次领取持久确定任务
  尝试预算，其他能力 Worker 不能用自己的限制提前使视频失败。旧无策略租约沿用
  原默认三次。失败使用持久次数，避免信任可修改的调用方 job 字典。
- 心跳覆盖下载、转码和上传；慢对象检查后再次验证当前租约。失去租约不确认输出，
  自有媒体进程取消后杀死并等待。任务池严格有界，停止时等待活动工作。
- 分片写入、源组装、冷字节读取和 outbox 对象检查移出全局锁；最终引用接受与 GC
  串行化，防止接受已被清理的对象。过期元数据先提交再删对象，避免跨存储回滚缺口。
- 冻结资源映射按最多 128 个视频缓存，但每次媒体访问仍检查当前状态；冷加载合并、
  失效 epoch、远端存在性检查和本地下载校验保持缓存语义。复用本地对象不替换已开读者。
- HTTP 独立路由、严格 framing/重复声明/JSON，绝对套接字期限及有界处理器；停服
  等待处理器和定时器再关库。授权拒绝非对象、重复、布尔或非有限时间声明。
- 完整源检查覆盖后半段损坏，异常诊断保留有限尾部；清理失败不掩盖原媒体异常。
  发布验证输出名称、对象完整性和依赖，状态向所有者提供有限失败原因。

## 部署和维护边界

本轮没有重跑 Patroni 主库提升、真实 S3 存储 HA、Compose 启动或跨主机分区；
旧 [HA 记录](../benchmarks/ha-results.md) 是历史证据。PostgreSQL 全局事务锁、
最终对象检查和保守 GC 仍限制写并发，慢存储可能延迟续租。Socket 期限无法强制
取消数据库/对象调用，断连后已接受操作仍可能提交，客户端需要查询状态再幂等重试。

心跳失效在下一次周期发现；远端调用有自己的后端期限。GOP 两秒是目标，不保证
源已存在对应关键帧。命令诊断使用临时磁盘，只有内存尾部有界。GC 宽限不是持久
pin，暂停未提交工作可能需重试；历史源、任务和凭据仍需运营保留策略。
CDN/国际部署、真实观看统计驱动的冷热/地域策略、GPU 管理、KMS 与商业 DRM
保留为外部部署/后续范围，不能据此把整套生产拓扑标记为已完成。
