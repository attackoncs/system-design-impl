# 设计：Google Maps参考实现

## 职责和版本化存储

| 模块 | 职责 |
| --- | --- |
| models/catalog/schema | 校验、写锁外图规范化/预处理、兼容SQL模式 |
| store/telemetry | 目录事务、身份、匹配、原子轨迹批次与交通 |
| cache | 固定加载条带、LRU和返回值隔离 |
| geo/navigation | 投影/裁切/距离、细图准确寻路、几何与指令 |
| routing_tiles/render | 分类层级拓扑、邻居URL、矢量/栅格 |
| artifacts | 独立持久不可变预生成瓦片 |
| tracking | 私有活跃导航、区域失效筛选、刷新/CAS及当前状态事件 |
| transport/http | 严格直接传输、角色路由、鉴权、容量和关闭 |
| credentials/maintenance/cli | 凭据文件所有权和后台资源所有权 |

SQLite WAL保存图/地址、RTree道路包围盒、交通及私有身份/位置。图校验、编码、hash和
空间行预处理移到写事务外，bulk安装仍占单写者，图UUID/hash/目录版本同事务推进。
旧读事务保留完整代；graph_versions持久记录见过的UUID/hash，跨中间版本或重启也拒绝
UUID下换内容。旧edges表原地增加默认local分类，规范导出省略默认值以保持旧hash。

副本仅含规范公开图/地址/许可证/交通，不含凭据、轨迹、replay或导航会话。
过期交通行保留在公开目录，避免同一revision仅因时间流逝而改变载荷；寻路时过滤过期。
相同revision必须内容和元数据一致，异源/回退冲突，输入先冻结并验证，安装原子。
时钟同步、版本保留、增量复制和目录容量仍需运维策略。

## 寻路、ETA和分层

Dijkstra按非负长度/速度寻路，一次SQL读绑定图、有效驾驶交通和按需邻接。步行/骑行
使用模式基线。请求内节点缓存复用于候选搜索、几何和指令，避免重复SQL。
max_nodes计所有候选总访问，耗尽413与不可达404不同。alternatives通过排除最佳路线前
64条边之一重复准确搜索，去重后按ETA排序；这是有界单边避让，不是完整K最短路或ML排序。

结果含geometry、精度5编码polyline、逐段距离/时长和简单出发/直行/左右转/掉头提示。
航向使用球面初始bearing并处理日期线；不具备真实转弯限制、信号灯、车道规则。
地址是固定数据规范化精确查找，坐标在1000米内吸附最近节点，不是全球地理编码。

道路分类local（默认）、arterial、highway。z16含所有道路，z12仅主干/高速，z8仅高速。
输出parent/children、共享节点跨层portal及source/target XYZ，入向主干道路也能标识入口。
每次默认最多5000节点/边，SQL预先LIMIT，不先读全图再检测超限。
三层真实分类视图已可执行，路径算法仍在细图准确搜索，没有使用未经证明的shortcut或
宣称分层加速。

## 位置与交通

凭据哈希保存。1..100条报告先规范化为独立标量，再等待写锁；取得锁后采样接收时间、
检查过去24小时/未来30秒窗口。用户事件ID绑定规范载荷，相同重试返回原结果，冲突整批回滚。
序列号和报告时间都递增才推进当前位置；迟到报告保留历史但不回退当前采样状态。

保留期按接收时间24小时计算，可能长于原客户端观测时间的24小时。上报仅清该用户过期
状态，索引支持的全局后台清理避免每次上报扫描所有用户。查询逻辑过滤及时，物理删除
可因排队/停机延后，不证明磁盘/备份法律擦除；已过期事件ID可重新使用。

匹配用RTree候选与100米内短路段切平面近似；经度沿段首端展开，避免日期线道路错误经过
本初子午线。明确航向需在60度内，同一有向段上前进、间隔1..120秒、0.5..50m/s，且观测
足够新才生成实时样本。五分钟窗口按接收顺序（同时间以行顺序解平）取每用户最后样本，
至少两个不同用户才平均。未过期管理员封路不会被聚合重开；非Kafka/Cassandra/HMM/ML服务。

## 自适应导航和交付

NavigationTracker只用于primary。私有SQL会话保存本人选项/路线/版本/过期及包含路线的祖先
瓦片，默认128会话、TTL900秒（最大3600）、每秒检查。变化道路包围盒与祖先区域预筛潜在
受影响用户，图改变或大量变化强制刷新，默认30秒全量刷新也发现当前路线之外的新更快选择。
区域筛选只是失效机制，不是最短路shortcut。

计算在导航写事务外，安装核对会话版本/过期，避免覆盖并发位置更新或复活删除。
position更新origin并重算，DELETE删除会话；不可达/预算错误作为当前错误状态交付，不捏造路线。
后台记录不含敏感信息的失败并重试，具体栅栏和恢复见[测试](../tests/)。

有限SSE页返回最新revision或heartbeat后关闭。after/Last-Event-ID重连要求客户端替换展示
当前路线，中间状态会合并，非持久逐事件回放；超前游标409。读取、移动、删除和事件均本人
鉴权/TTL检查，事件最多等5秒、最多占HTTP槽位四分之三。会话不进入公开目录，不代表完整
手机逐转弯客户端、可靠消息队列、多主机状态HA或训练ETA模型。

## 地图生成与归档

WGS84投影到XYZ Web Mercator，极区及舍入钳制，支持z0..21。裁切处理公共边和日期线展开。
GeoJSON与真实256像素RGB PNG源于相同裁切段。URL查询返回当前UUID、本格及最多8个唯一邻居，
经度环绕、极区夹紧，未提供完整手机viewport渲染器。

冷渲染默认最多5000候选边/10000段，超过返回413，缓存/归档命中免重光栅化。
TileArchive为独立SQLite对象存储参考，按图UUID/XYZ/格式定位并绑定graph_hash，读取校验
checksum及16MiB单对象上限；已有键内容不可替换。显式预生成默认每批256坐标/64MiB载荷，
两种格式生成后原子发布；期间图变化不能混代，可保留完整旧代。必须与目录分文件；不是
云对象复制/CDN或全球预生成。

源站读先验证active图，再用缓存或归档。替图后旧URL410，外部CDN已持有内容仍因版本URL不可变
而有效；支持ETag列表/弱比较和304。归档保留/GC、地图样式/字体、MVT/gzip和全球流水线待扩展。

## 并发、角色和关闭

邻接与瓦片缓存有界条目LRU，固定64条带合并同key冷加载，加载器不持全局LRU锁，返回值隔离。
邻接按节点缓存不可变JSON文本，访问时解析独立边列表，避免每访问节点深拷贝整个密集瓦片或重复复制嵌套字典。条目上限不代表固定bytes/RSS；
大细图瓦片、图预处理和安装仍有随数据量增长的内存/写者成本。

主服务拥有写入/追踪，副本拉取认证全量公开目录到独立文件、失败保留旧完整代；网关只接受
公开读，需X-Region，在配置的同区域内对传输/5xx/非法回复重试，4xx直接返回，禁止跟随redirect。
直接HTTPS保留正常身份验证，拒绝歧义/截断framing，有界正文，一次预算涵盖准入和副本尝试；
复制凭据不会跟到跳转目标。输入JSON/framing严格，私有正文前鉴权。

HTTP默认32处理器、10秒套接字请求预算，正文和响应有限。绑定成功后才启动复制、导航、
30秒维护；ExitStack先关HTTP并排空处理器，再停/回收后台I/O。取消网络工作后底层退出才释放容量。
系统DNS、SQLite、CPU不能被套接字取消强行中断，不承诺硬关闭或完整计算期限。
凭据先独占写/fsync文件再建SQL用户，普通失败只清身份匹配的新文件，不是跨文件系统/SQL崩溃原子协议。

共识发现、写主HA、TLS/身份、真实云地域/CDN、备份和持续规模验收仍为后续工作。
