# 需求：Google Maps，第19章

依据仓库《System Design Interview.md》7294–8019行。核心为位置批上报、导航/ETA、
地图渲染；组件标准库/SQLite独立可运行，使用小型授权合成道路，不含初始范围外的
商家照片或多站点优化。

- 原子导入有向图：WGS84节点、正长度/模式速度、收费与可选local/arterial/highway分类。
  保持单向/模式/避收费约束，区分不可达与搜索预算，单路线绑定同一图/交通快照。
- 输出geometry、编码polyline、几何方向和可重现ETA。候选为有界单边避让，不声称完整
  K最短路/训练预测；地理编码限固定数据，节点吸附距离有界。
- 细图邻接按需加载，分类z16/z12/z8视图含跨瓦片/跨层入口；准确寻路仍在细图运行。
- 认证轨迹批次具备用户级持久幂等、冲突整批回滚、序列/时间不回退、接收时间保留和航向匹配。
  仅足够新的有效驾驶观测生成实时样本，聚合不同用户，不重开未过期管理员封路。
- 私有导航会话有容量与TTL，根据图/交通变化筛选刷新并周期检查新更快路线，CAS保护移动/删除。
  有限SSE当前状态页支持本人鉴权、游标重连及合并，不把它当持久事件队列。
- z0..21真实GeoJSON/PNG，极区钳制、日期线裁剪、唯一邻居URL、版本URL/ETag及冷工作预算。
  独立持久不可变/checksum预生成归档，批次有界原子，源站先检查active图。
- 缓存隔离并合并冷加载，HTTP/事件容量及直接传输有界，严格JSON/framing，私有正文前鉴权，
  只同区域公开读故障切换，后台组件有明确启动/取消/排空所有权。
- 真实HTTP公开目录复制到独立数据库，拒绝同版本改内容、UUID换图、异源/回退及半安装。
  不导出凭据、轨迹、replay或导航会话，不记录精确坐标/凭据访问日志；保留规则说明物理删除延后。

验收包括独立最短路参考、真实PNG/GeoJSON、分层、归档重启/不可变、交通过期/重规划、
私有会话/SSE、位置并发/幂等/保留、生命周期及真实独立进程故障，报告实际范围。
全球授权道路、转弯/公交规则、ML ETA、流式/分布式数据层、HA、真实云地域/CDN及书中
容量仍为扩展。提交遵循用户授权范围，需求/任务文件延续本地保留约定。
