# 第6章复审实测 — 2026-10-27

Windows11 / CPython3.13.9，运行库标准库。基线为只读HEAD7c1a49c的src副本，
同一脚本/解释器在独立进程运行，没有混合导入。所有原始数据均保留。

## 功能和并发

108项基线测试14.93秒；最终154项18.56秒。禁用无关插件，因已有缓存/临时目录
权限使用无缓存及工作区新临时目录；-Werror、无跳过/无警告过滤。Hypothesis
生成样本不同，测试总耗时不用于评价算法性能。

[四进程记录](processes-2026-10-27.json)：spawn+屏障确认四个不同PID，
每进程2002键，SHA-1/MD5/SHA-256三函数，每函数初始/改权/加节点/删除
四阶段及三个副本候选摘要一致；部分进程逆序构建成员。该脚本是本机算法
一致性验证，没有网络请求、成员同步或物理迁移。

[章节实验](chapter-2026-10-27.json)：10000键，1/100/200虚拟节点时CV为
1.01794/0.05789/0.06078，有限样本并非单调。加第11个节点，环迁移969、
取模9066，区间选择同样筛出969；删除节点迁移848且全部来自被删节点。
将server-0权重200→400，迁移767且全部迁向它；恢复后路由完全一致。
原examples/demo.py也完整通过，历史三至四节点迁移249/1000。

## 性能对照 / Measured comparisons

构造/规划/查找各5次，新增/移除各10次，表为中位数ms；完整样本在JSON中。
查找每次10000键，线程池按线程分块，8线程总量不变；包括调用/线程调度
成本，不是每键p95，也不是多机吞吐压测。基准与测试/图更新分开运行。
