来源：根目录 `System Design Interview.md` 第 24 章，章节起始行 11227。

状态：开源及并发复核完成（2026-11-05）；99项测试通过，31.374秒；真实本机HTTP/SMTP九进程验证，保留生产范围缺口。

## 范围

HTTP 邮件收发、附件、已读筛选、主题/发件人/正文搜索及反垃圾/病毒接口；身份认证不在本章主体范围。

## 实施任务

- [x] T1. 编写需求/设计，分离元数据、对象字节、投递队列及倒排索引。
- [x] T2. 实现 HTTP 收/发件箱、已读 CAS、50 条分页与静态身份适配点。
- [x] T3. 实现持久化发送任务、真实本机 SMTP、MIME 接收与网关 spool；未实现或执行公网外发。
- [x] T4. 实现独立 HTTP 对象存储、SHA256 检查、本人附件授权；每附件 2 MiB，完整 RFC 8 MiB。
- [x] T5. 实现 Scanner 接口、隔离区、扫描不可用重试；仅测试标记规则，默认未配置扫描器时隔离全部。
- [x] T6. 实现双主用户分片与两个独立异步只读副本；去重/墓碑/租约恢复，未声称副本可自动写主提升。
- [x] T7. 实现主题/发件人/正文倒排词项索引；主库同事务删除同步，副本最终一致。
- [x] T8. 验证真实 SMTP、确认丢失、附件校验、节点重启、读状态冲突、隔离和副本搜索。

## 验收门槛

- 正确性、持久化重启、幂等和故障路径有可重复测试。
- 分布式能力须用实际独立进程/网络验证，模拟实现单独标注。
- 外部云服务/供应商使用可替换适配器；未配置凭据时不能宣称真实服务已验证。
- 原书规模和可用性数字是设计目标，不由本机测试直接证明。
- 仅在用户要求后提交；docs 下 requirements.md/tasks.md 延续不提交的约定。

## 验收证据与后续边界

以下测试及延迟数字为 **2026-10-20历史证据**；当前99项测试与实测结果见
[验证报告](../benchmarks/results.md)。

- 6 项核心存储测试 + 3 项真实九进程网络测试全部通过（21.838 秒）。
- 40 封邮件均经 HTTP/SMTP 投递且可从副本搜索，唯一网关投递 40；副本搜索 p95 76.077ms。
- 主节点退出后副本可读、写入 503；网关确认丢失和扫描不可用后重启恢复无重复。见 ../benchmarks/results.md。
- 暂无真实 AV、公网外发、主副本选举、对象/队列复制、自动隐私保留和对象 GC；本机测量不代表十亿用户规模。
- 本次复核不提交或推送；提交状态与章节验收分开记录。
