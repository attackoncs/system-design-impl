- API、SQL、JSON字段、命令、变量名及协议标识符保留；代码块及其注释按底本原样保留，独立公式与数值含义不改写。中英文数量单位作等值表达。
- 图片仍使用原文的远程链接，图注和替代说明已中文化；**图内嵌入的英文标注未重绘**，可结合术语表阅读。离线打开时，远程原图可能无法显示。
- 历史日期、业务规模、费用、性能样本和参考链接忠实保留，没有更新为2026年的现状，也没有声称所有旧网址仍能访问。

- 合并阅读版对第17、18章的QPS表及第22章表12、17、18作可读重排，均带“译校说明”；底本缺失的单元格写明“原稿缺项”，没有补造内容。分章版保留底本结构，便于逐行核对。

## 重新核验或生成合并版

在仓库根目录、可访问本地英文原稿的情况下：

```powershell
python docs/translations/system-design-interview/verify.py
python docs/translations/system-design-interview/build.py
```

额外包含前次第27章参考译稿：

```powershell
python docs/translations/system-design-interview/build.py --include-payment-reference
```

只生成逐章拼接版、不重排损坏表格：

```powershell
python docs/translations/system-design-interview/build.py --no-table-repairs
```

再次执行不带参数的`build.py`即可恢复默认范围及表格重排。`verify.py`读取英文原稿和译文并更新校验报告，`build.py`重建合并阅读版；它们不修改英文原稿和各实现子项目。结构化原稿疑点另见[editorial-notes.json](editorial-notes.json)。
